教程指南 · 使用注意事项
快速上手
1
配置魂玉：在「魂玉配置」页选择 A1~A7 槽位的魂玉及副词条，A7 为专属招式槽位。
2
加点潜能：切换到「潜能树」页，左键点击节点加点、右键洗点，选择潜能元素（冰/雷/毒）。
3
查看结果：右侧「数值汇总」实时展示各项属性加成，「特殊机制」展示触发的被动效果。
魂玉配置注意事项
槽位规则
  • A1~A6 为普通魂玉槽位，可装备任意普通魂玉
  • A7 为专属招式槽位，仅可装备专属招式类魂玉
  • 每个魂玉最多可选择 4 条副词条
魂玉互斥
  • 同系列元素奔涌魂玉互斥（冰/雷/毒元素奔涌不可同时装备）
  • 选择互斥魂玉时系统会自动提示冲突
  • 配置前请规划好build方向，避免槽位浪费
词条互斥
  • 稀有词条可在不同魂玉间重复选择
  • 普通词条不可重复，同一词条仅能出现一次
  • 副词条数值为百分比形式，直接填入即可
特殊机制魂玉
  • 烈元诀：武器伤害 -5%，但提供 30% 元素暴击率（额外加成，不受暴击上限限制）
  • 元爆星陨：星陨流派核心魂玉，与潜能「星爆术」联动（需装备此魂玉星爆术才生效）
  • 三才汇聚：三才流派核心魂玉，与潜能「三才怒」联动（需装备此魂玉三才怒才生效）
  • 冰/雷/毒元素奔涌：奔涌流派核心魂玉，提供「元素奔涌状态」，是元化劲/狂元爆/奔元怒/三斩变体能生效的前置（三选一互斥，详见潜能系统奔涌流派说明）
  • 合道化气 / 枚卜 / 火正等机制魂玉请按游戏内实际效果配置
潜能系统注意事项
点数与流派
  • 潜能总点数为 48 点，需合理分配
  • 共四大流派：水火、三才、奔涌、星陨
  • 每流派 14 个节点，部分节点为多分支结构
加点操作
  • 左键点击：对该节点加点（消耗1点）
  • 右键点击：洗去该节点1级（返还1点）
  • 前置节点必须点满后才能解锁后续节点
  • 部分节点为「或条件」前置，满足任意一条路径即可解锁
潜能元素选择
  • 在潜能树页右上角选择元素：冰 / 雷 / 毒
  • 元素选择影响潜能提供的元素伤害加成分配到对应元素
  • 奔涌流派「三斩变体」名称随元素切换（如雷元素→天雷狂斩）
  • 切换元素后数值实时刷新，无需重置
条件触发节点
  • 三才怒：需魂玉装备「三才汇聚」才生效，获取三才印时 +12% 攻击力
  • 星爆术：需魂玉装备「元爆星陨」才生效，触发星爆后 +30% 元素伤害
  • 奔涌元化劲/狂元爆/奔元怒：需装备元素奔涌魂玉获得「元素奔涌状态」才实际生效（详见下方奔涌流派前置说明）
  • 三斩变体：需装备元素奔涌魂玉，断厄斩才变为元素变体（雷→天雷狂斩提供100%振刀反击伤害）
  • 条件不满足时，节点在模拟器中仍计入数值（理论值），但实际游戏中触发效果无法生效
焚身炽焰机制
  • 水火流派终极节点，开启后失去全部体力加成
  • 每 1% 体力值转化为灼烧伤害 +0.3%
  • 点出此节点后，体力词条的收益将转化为灼烧伤害
  • 配置时注意：高体力build配合此节点收益显著
四象·破罡
  • 三才流派「怒罡赋」：四象反击命中获得 20% 罡气伤害加成
  • 奔涌/星陨流派「破罡」节点：每级 +1% 罡气伤害
  • 罡气伤害对破罡武技、四象反击等有效
  • 点数计算已自动纳入数值汇总
奔涌流派：魂玉前置要求（重要）
核心机制：奔涌流派多个节点的加成依赖「元素奔涌状态」，该状态只能通过装备元素奔涌魂玉获得。未装备对应魂玉时，这些节点的加成在实际游戏中不生效。
所需魂玉（A1~A6槽位，三选一互斥）魂玉自带效果激活的奔涌潜能节点
冰元素奔涌攻击力 +15%，元素累积效率 +50%元化劲 / 狂元爆 / 奔元怒 / 三斩变体（冰）
雷元素奔涌攻击力 +12%，雷元素伤害 +55%元化劲 / 狂元爆 / 奔元怒 / 三斩变体（雷→天雷狂斩，+100%振刀反击伤害）
毒元素奔涌攻击力 +20%，毒元素伤害 +25%元化劲 / 狂元爆 / 奔元怒 / 三斩变体（毒）
各节点生效条件说明：
  • 元化劲（+15%攻击力）：元素奔涌状态结束后触发，获得攻击力提升——需先有元素奔涌状态，状态结束后才生效
  • 狂元爆（+20%元素伤害）：处于元素奔涌状态期间，元素伤害提升
  • 奔元怒（+15%攻击力）：元素奔涌持续期间攻击力提升
  • 三斩变体：装备元素奔涌魂玉后，断厄斩变为对应元素变体；雷元素变体「天雷狂斩」额外提供 100% 振刀反击伤害
模拟器说明：当前版本点出上述节点后，属性会直接计入数值汇总（为理论最大值）。实际游戏中请确保已在 A1~A6 槽位装备对应元素的元素奔涌魂玉，否则这些加成无法实装。奔涌流派build必须绑定一枚元素奔涌魂玉。
数值计算规则
暴击率计算（重要）
普通暴击率基础 5% + 词条暴击率，上限 47%
元素暴击率烈元诀 30% 为额外加成，不受 47% 上限限制
总元素暴击普通暴击率 + 元素额外暴击率，无上限
注意：47% 上限仅限制「基础5% + 词条暴击率」部分，烈元诀等魂玉/潜能提供的元素暴击率为独立加成区间。
属性叠加方式
  • 所有百分比加成采用加法叠加
  • 数值汇总分别展示：副词条 / 魂玉后缀 / 潜能 / 法宝 / 总计
  • 攻击力、伤害加成等均为最终乘区前的加算值
  • 元素伤害按潜能元素选择分配到冰/雷/毒对应字段
法宝系统
  • 法宝分阳极（4项）和阴极（4项）
  • 需先在下拉框选择「启用法宝」才会显示配置项
  • 法宝加成独立计入数值汇总的「法宝」列
  • 重置魂玉时会同时重置法宝配置
操作与重置说明
重置魂玉
  • 清空所有魂玉槽位配置（A1~A7）
  • 同时重置法宝配置
  • 保留潜能树加点状态
  • 适合更换build方向时使用
重置潜能
  • 清空潜能树所有节点加点
  • 剩余点数恢复为 48/48
  • 保留魂玉配置和法宝配置
  • 重置后可重新点击节点加点，无异常锁定
数据保存
  • 点击「导出配置」可将当前配置保存为 JSON 文件
  • 点击「导入配置」选择之前导出的 JSON 文件即可完整恢复
  • 配置默认仅保存在页面内存中，刷新后丢失，建议导出留存
常见问题 FAQ
Q：为什么有些节点点不了？
A：潜能节点有前置依赖，必须先将前置节点点满（maxLv）才能解锁。部分节点为「或条件」，满足任意一条前置路径即可。
Q：潜能元素选冰/雷/毒有什么区别？
A：决定潜能提供的元素伤害加成分配到哪种元素，同时影响奔涌三斩变体的名称和效果（如雷元素→天雷狂斩提供100%振刀反击伤害）。请根据魂玉build选择对应元素。
Q：暴击率显示超过47%是bug吗？
A：不是。47%仅限制基础5%+词条暴击率部分，烈元诀等提供的元素暴击率为额外加成，总元素暴击率无上限。模拟器已按两段式正确计算。
Q：焚身炽焰点了之后体力加成没了？
A：这是正常机制。焚身炽焰会将全部体力加成转化为灼烧伤害（每1%体力→灼烧伤害+0.3%），属于主动trade-off，适合高体力灼烧build。
Q：三才怒/星爆术加成为什么不生效？
A：这两个节点为条件触发：三才怒需魂玉装备「三才汇聚」，星爆术需魂玉装备「元爆星陨」。请检查魂玉配置中是否包含对应魂玉。
Q：重置潜能后节点无法点击怎么办？
A：当前版本已修复此问题。重置潜能会完整初始化所有58个节点状态，剩余点数恢复48/48，可正常重新加点。如遇异常请刷新页面。
Q：奔涌流派点了元化劲/狂元爆/奔元怒，实际游戏中没效果？
A：这三个节点依赖「元素奔涌状态」，必须在 A1~A6 槽位装备冰/雷/毒元素奔涌魂玉之一才能激活。模拟器中点了节点就直接计入数值（理论最大值），但实际游戏中未装备元素奔涌魂玉时这些加成不生效。奔涌流派build必须绑定一枚元素奔涌魂玉。
Q：三斩变体/天雷狂斩怎么触发？
A：需同时满足两个条件：①潜能点出奔涌流派「三斩变体」节点；②魂玉装备对应元素的元素奔涌魂玉。满足后断厄斩变为元素变体，其中雷元素变体「天雷狂斩」额外提供 100% 振刀反击伤害。潜能元素选择需与魂玉元素对应。
